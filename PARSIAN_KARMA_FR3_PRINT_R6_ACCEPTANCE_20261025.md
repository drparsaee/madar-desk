## Accuracy boundaries

- This is a faithful **structural reconstruction** from the actual FR3 object coordinates and embedded graphic, **not** execution of FastReport PascalScript or pixel-perfect reference proof.
- Source fields that do not exist in the current R5 ledger (seller/buyer address, bank account, previous balance, receipt details, genuine official invoice number) are intentionally not fabricated.
- The sample carries a clear test/draft watermark and is not an issued fiscal invoice. No Parsian production database has been changed.
- A direct comparison with a Parsian-generated PDF from the same template and same data would be required for a formal pixel-level parity claim.
