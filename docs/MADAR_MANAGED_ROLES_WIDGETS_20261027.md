# مدار | نقش‌های نمایشی مدیریت‌شده و ویجت‌های شخصی | 2026-10-27

## تصمیم مالک

«سطح نمایش» یک انتخاب دلخواه توسط هر کارمند نیست. مدیرکل باید بتواند برای هر حساب، قالب نقش، سطح امکانات قابل‌نمایش و استثناهای همان حساب را تعریف کند. پنج قالب اولیه: **مدیرکل، مدیر ارشد، مدیر میانی، مدیر واحد، کارمند**؛ مدیرکل می‌تواند نقش‌های سفارشی بسازد، آن‌ها را ویرایش/حذف کند و به کاربران تخصیص دهد. حساب مالک شخصی در اولین اجرا **نمای مدیرکل** دارد.

## تفکیک الزام‌آور امنیت و ظاهر

- `role` میزبان LAN همچنان یکی از `admin/editor/viewer` است و **تنها این شناسه و مجوزهای سمت Host** مرجع اجرای عملیات است؛ نقش نمایشی مستقل `displayRole`، `displayMode` و `displayFeatures` فقط میزان نمایش ابزار را کاهش می‌دهد. عنوان «مدیر ارشد» هیچ API مدیریتی را مجاز نمی‌کند.
- لیست نقش‌ها فقط برای ادمین LAN از `/api/display-roles` دریافت و ویرایش می‌شود؛ `/api/me` آخرین وضعیت مؤثر حساب را به خودش می‌دهد. کاتالوگ در فایل تنظیمات جداگانه کنار دیتای کاربران LAN ذخیره می‌شود؛ نه در Git و نه در بستهٔ Export عمومی تسک‌ها.
- قالب‌ها ممکن است برخی امکانات نمایش را محدود کنند. حتی اگر نمایش یک ابزار باز باشد، ACL شبکه، محدوده پروژه، financeView/financeEdit و محدودیت‌های هسته حسابداری باید روی میزبان دوباره بررسی شوند.
- حالت solo یک حساب محلی با نمای مدیرکل است؛ برای مدیریت چند حساب، لازم است میزبان حساب‌های LAN راه‌اندازی شده باشد. حساب‌های مستقل سیستم حسابداری با حساب‌های LAN یکی فرض نشده‌اند.

## ویجت ساعت و تاریخ

- محل اصلی تنظیمات ویجت، «تنظیمات مدار» است؛ همان کنترل‌ها به صورت اختیاری در خود ویجت نیز قابل دسترسی‌اند. شخصی‌سازی برای هر دستگاه محلی است و تنظیمات آن به دادهٔ کارها یا تاریخ سند حسابداری دست نمی‌زند.
- نمایش ساعت/تاریخ/هر دو/مخفی؛ تم شیشه‌ای روشن/تیره/شفق؛ اندازه کوچک/معمولی/بزرگ؛ ساعت ۱۲/۲۴ساعته و تاریخ کامل/خلاصه.
- جای‌گیری در نوار بالا، پین در چهار گوشهٔ صفحه یا شناور در مختصات نسبی. جابه‌جایی با drag از دستگیره یا کلیدهای جهت‌دار؛ موقعیت باید هنگام تغییر ابعاد پنجره محدود شود و ویجت از صفحه بیرون نرود.
- طرح شیشه‌ای فقط الهام‌گرفته از جلوه blur/translucency رابط‌های امروزی است و از فایل/فونت/تصویر انحصاری اپل استفاده نمی‌کند.
