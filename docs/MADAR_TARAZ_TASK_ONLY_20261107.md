# قرارداد جداسازی مدار و تراز (سورس، ۲۰۲۶/۱۱/۰۷)

**مدار** مدیریت کار، پروژه، برد، کارت، فهرست، زمان، گزارش و اتوماسیون را ارائه می‌کند. **تراز** نرم‌افزار مستقل حسابداری خواهد بود. کدهای تاریخی حسابداری برای ارجاع باقی مانده‌اند، اما در نسخه جدید مدار صفحه حسابداری ساخته نمی‌شود؛ میزبان Windows درخواست /accounting.html را با 404 پاسخ می‌دهد و مسیرهای مالی LAN از allowlist حذف شده‌اند. متدهای مالی قدیمی WebView2 نیز در مرز Python رد می‌شوند.

## قرارداد خروجی یک‌طرفه

- فراخوانی tarazIntegrationStatus() نتیجه شامل supported، mode، pending، postingEnabled=false و message برمی‌گرداند.
- فراخوانی tarazIntegrationQueue(taskId, expenseId?) شناسه‌ها را در **داده ذخیره‌شده** مدار جست‌وجو می‌کند، دسترسی حساب LAN و وضعیت ذخیره/آفلاین را کنترل می‌کند و تنها یک پیشنهاد می‌نویسد؛ نتیجه دارای queued=true، id و postingPerformed=false است.
- صندوق مستقل دو برنامه در Windows: %LOCALAPPDATA%\\Madar-Taraz-Bridge\\pending\\<uuid>.json . هیچ پوشه یا نام فایل از کلاینت دریافت نمی‌شود؛ نوشتن اتمی از فایل موقت .tmp به .json انجام می‌شود.
- محتوا: schema=1، source=madar، id، taskId، title، projectId، createdUtc؛ در صورت انتخاب هزینه موجود: expenseId و فقط برای مبلغ معتبر ریالی amountRial از نوع رشته.
- طرف حساب، شرح هزینه، شماره سند، حساب‌ها، بانک، داده هویتی، تمام کارت‌های پروژه، رمز و جزئیات مالی در خروجی نیستند. هیچ ثبت دفترکل، فاکتور، پرداخت، تبدیل تومان به ریال یا تغییر وضعیت در تراز با ارسال پیشنهاد اتفاق نمی‌افتد.
- مصرف‌کنندهٔ تراز باید JSON را اعتبارسنجی کند، id را برای idempotency نگه دارد، نتیجه را برای **بازبینی انسانی** نشان دهد و تنها بعد از تأیید کاربر در دیتابیس اختصاصی خودش ثبت کند. انتقال موفق به معنای ثبت سند نیست.

## مرز آزمون

آزمون tests/test_taraz_exchange.py تنها با APPDATA و LOCALAPPDATA موقت اجرا می‌شود. ساخت React با خروجی مستقل و بدون نصب انجام می‌شود. آزمون‌های قدیمی که رفتار حسابداری یکپارچه را انتظار دارند باید به مجموعه legacy منتقل شوند و معیار پذیرش نسخه task-only نیستند.

**وضعیت:** سورس مدار برای اتصال سمت تراز و آزمون پذیرش دو برنامه جداگانه آماده شده؛ نصب، ادغام روی داده واقعی و تأیید GUI کاربر در این تغییر انجام نشده است.
