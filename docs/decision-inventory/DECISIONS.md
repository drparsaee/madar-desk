- واحد هدف حسابداری **ریال** است؛ تکیه قدیمی بر TOMAN را بدون Migration/تبدیل تأییدشده ادامه ندهید. شاهد: money_policy.py و RIAL_BACKUP_MIGRATION_RUNBOOK_20261022.md.

- پیش‌نمایش GUI، Import آزمایشی یا بکاپ، به‌خودی‌خود نشان‌دهنده تکمیل مهاجرت عملیاتی نیست.
