# گزینه‌های میزبانی Madar Web — 2026-11-06

این یادداشت برای انتخاب VPS است، نه تأیید کیفیت عملیاتی فروشنده. قیمت‌ها از صفحات قابل مشاهده در تاریخ بررسی استخراج شده‌اند؛ موجودی، مالیات، هزینهٔ تمدید، کیفیت واقعی شبکه و شرایط پشتیبانی در checkout یا با تیکت فروشنده تأیید نشده‌اند.

## نیاز فنی این پروژه

- Linux VPS با KVM یا مجازی‌سازی معادل و دسترسی مدیریتی واقعی.
- حداقل 2GB RAM؛ برای شروع کم‌ترافیک قابل استفاده است.
- ترجیحاً 2 vCPU؛ یک vCPU فقط برای پایلوت کوچک و بار کم.
- 20GB فضای SSD/NVMe حداقل عملی؛ 40GB فضای NVMe حاشیهٔ بهتر برای SQLite و فایل‌های عملیاتی می‌دهد.
- IPv4 عمومی، SSH، امکان نصب Node.js 26.8+ و `node:sqlite`، systemd، Caddy و بازکردن TCP 80/443.
- پورت API داخلی 8781 نباید به اینترنت expose شود.

## هاست اشتراکی cPanel موجود

این پروژه را فعلاً روی هاست اشتراکی cPanel قرار نمی‌دهیم. مستند رسمی cPanel که در 20 August 2026 به‌روزرسانی شده، برای بسته‌های رایج EasyApache نسخه‌های Node 16، 18، 20 و 22 را فهرست می‌کند؛ Node 26.8 در آن فهرست نیست. cPanel در نسخه‌های جدید امکان Web Apps برای Node.js دارد، اما این موضوع به‌تنهایی دسترسی به Node 26.8، systemd، Caddy و کنترل کامل reverse proxy را برای پلن فعلی کاربر ثابت نمی‌کند.

- cPanel Node.js deployment: https://docs.cpanel.net/knowledge-base/web-services/how-to-install-a-node.js-application/

## نتیجه

- اگر هزینه اولویت قطعی است: KelonCloud پلان دوم فقط پس از تأیید کتبی root/Ubuntu یا Debian/Node 26.8 انتخاب شود؛ تک‌هسته‌ای بودن آن را برای شروع کم‌ترافیک محدود می‌کند.
- اگر هدف نصب مستقیم با کمترین ابهام منابع است: PikoHost پلن 2 مشخصات root، KVM، 2CPU و 40GB NVMe را شفاف‌تر اعلام کرده است.
- هیچ‌کدام خریداری یا به‌عنوان فروشندهٔ نهایی انتخاب نشده‌اند. پیش از پرداخت، از پشتیبانی فروشنده تأیید بگیرید که Ubuntu 24.04 یا Debian 12/13، root واقعی، IPv4 عمومی، Node 26.8+، systemd و دسترسی ورودی 80/443 مجاز است.
- مقصد پشتیبان خارج از VPS باید جداگانه انتخاب شود. بکاپ روی همان VPS به‌تنهایی disaster recovery نیست.
