## ماتریس متغیرها و Windows 7

هشت محیط Chromium با اندازه‌های 320×640، 375×812، 390×844، 430×932، 768×1024، 1024×768، 1366×768 و 1920×1080؛ زبان fa-IR/en-US؛ منطقه زمانی تهران، برلین، توکیو، لس‌آنجلس، نیویورک و UTC؛ تم روشن/تاریک؛ کاهش حرکت و حرکت معمول؛ لمسی و دسکتاپ؛ DPR از 1 تا 3. کلیپ‌شدن دیالوگ، اسکرول سراسری، Escape منو و خطای JavaScript بررسی شد.

**شبیه‌سازی Windows 7 فقط User-Agent بود.** میزبان همچنان Windows 10 Pro x64 build 19045 است. Hypervisor فعال گزارش شد، اما Hyper-V مدیریت ماشین مجازی فعال نبود؛ VirtualBox/VMware/QEMU و ایمیج/مجوز معتبر Windows 7 در مسیرهای مرسوم پیدا نشدند. نصب‌کننده فعلی صراحتاً MinVersion=10.0.17763 دارد و Python 3.12 و WebView2 فعلی هم Windows 7 را پشتیبانی نمی‌کنند. اجرای واقعی روی Windows 7 انجام نشده و سازگاری ادعا نمی‌شود.

## گیت‌های باز

Full Python قدیمی در مبنای Native: 205 ماژول کشف، 204 اجرا، 174 موفق، 30 ناموفق، بدون timeout، 1847 تست. 10 ماژول منحصراً مربوط به قرارداد حسابداری حذف‌شده و 20 ماژول ترکیبی task/LAN/UI و حسابداری سابق هستند. شکست مستقل یک ماژول کاملاً task-only از این شواهد اثبات نشده، ولی رفتار task در 20 ماژول ترکیبی هنوز به‌طور کامل جداسازی و بازآزمون نشده است. آزمون‌ها حذف یا به‌دروغ موفق اعلام نشده‌اند.

Full Python پس از ادغام در نسخه مشترک: **206 ماژول کشف، 205 اجرا، 175 موفق، 30 ناموفق، بدون timeout، 1854 تست**. مقایسهٔ مجموعه‌های نام ماژول‌ها و وضعیت تک‌تک ماژول‌ها نشان داد که **تمام 204 ماژول مشترک دقیقاً وضعیت pass/fail پیشین را حفظ کرده‌اند**؛ تنها ماژول تازه و موفق، test_p1_active_surfaces.py است. بنابراین در سطح ماژول شکست تازه‌ای ناشی از ادغام مشاهده نشد. این مقایسه جای بررسی تک‌تک assertionهای قدیمی را نمی‌گیرد.

برای اجرای مجدد کامل با حفاظت از APPDATA می‌توان از tools/p1_full_legacy_audit.py با آرگومان --report و مسیر JSON تازه خارج از checkout استفاده کرد؛ فرمان هنگام وجود شکست legacy به‌درستی exit غیرصفر می‌دهد و گزارش را پاک نمی‌کند.

برای گیت سریع، py -3.12 -B tools/p1_task_only_gate.py اجرا می‌شود (72 تست). برای گسترهٔ بیشتر، py -3.12 -B tools/p1_task_only_gate.py --extended با 76 ماژول منتخب قابل‌تکرار است. نتایج بدون حذف هیچ ماژول قدیمی از اجرای full-suite ثبت شدند.

باقی‌مانده: دو رایانه فیزیکی LAN، HTTPS و گواهی معتبر در هاست واقعی، تست عملیاتی Backup/Restore و مهاجرت روی داده واقعی (عمداً اجرا نشده)، ماشین مجازی واقعی Windows 7/11، بازبینی دستی دقیق کنتراست و دسترس‌پذیری، و امضای Authenticode (سه فایل 1.0.25 NotSigned هستند). تطبیق دارایی نسخه 1.0.23 GitHub از حالت نامشخص خارج شد: فایل عمومی Compact بود و بایت‌های دانلودشده هش یکسان داشتند.

نکتهٔ ظاهری گزارش خط فرمان بسته 1.0.25: دو پیام چاپی build/QA هنوز رشتهٔ قدیمی P1_V124 را نمایش می‌دهند. این نام رشته در log است، نه شماره نسخهٔ manifest، EXE، Setup یا pointer نصب QA؛ تمام آن‌ها جداگانه 1.0.25 تأیید شده‌اند. برای حفظ همخوانی هش و commit کاندید immutable، سورس آن پس از تولید فایل‌ها دست‌کاری نشد؛ این متن پیام باید در کاندید بعدی اصلاح شود.

**حکم:** توسعه قابل‌آزمون و QA مصنوعی P1 پیش رفته و خروجی 1.0.25 صرفاً candidate است. تا حل گیت‌های فوق، برچسب production-ready یا public release معتبر نیست.
