# مدار وب: گانت و گفت‌وگوی پروژه/کارت

وضعیت: پیاده‌سازی در سورس شاخه `feat/madar-web-pwa-20261106`؛ **انتشار عمومی و پذیرش نسخه نصب‌شده انجام نشده است**.

## معماری

- گانت روی داده عملیاتی Task کار می‌کند و `plannedStart` / `plannedEnd` را مستقل از `dueDate` و زمان کار نگه می‌دارد. نماهای روز، هفته و ماه، فیلتر، رابطه وابستگی و جابه‌جایی دستی دارد؛ موتور زمان‌بندی خودکار ندارد.
- بخش «نمای زمان» قبلی همچنان مستقل از گانت و گزارش مدت‌زمان کار باقی مانده است.
- گفت‌وگوی وب با API هم‌مبدأ، Cookie/CSRF، SQLite مستقل از Snapshot و ACL سرور ذخیره می‌شود. `Viewer` فقط در محدوده پروژه مجاز می‌خواند؛ `Editor` پیام می‌فرستد و متن خودش را ویرایش/حذف می‌کند؛ مدیر می‌تواند پیام سایر افراد را حذف کند، نه ویرایش.
- درخواست نوشتن پیام `Idempotency-Key` دارد. تکرار درخواست یکسان همان نتیجه را برمی‌گرداند؛ استفاده مجدد از کلید با محتوای متفاوت خطا است. پس از جابه‌جایی کارت بین پروژه‌ها، تاریخچه پروژه قبلی **در دیتابیس باقی می‌ماند ولی به پروژه جدید منتقل یا نمایش داده نمی‌شود**؛ ویرایش و حذف آن نیز مسدود می‌شود. این محدودیت برای پیشگیری از افشای گفت‌وگوی خصوصی لازم است.
- SQLite `PRAGMA user_version=3`: نسخه 1 ساختار حساب و Snapshot، نسخه 2 پیام و Receipt، نسخه 3 نگهداری نسخه پیشین متن قبل از Edit/Delete در `web_conversation_revisions`. این تاریخچه فقط سمت سرور نگهداری می‌شود و API فهرست عمومی آن ندارد.

## داده، نسخه و بازیابی

- `server/admin.cjs backup` با SQLite backup و `restore:verify` بکاپ‌های نسخه 1، 2 و 3 را بررسی می‌کند؛ نسخه 3 جدول تاریخچه و گفت‌وگو را نیز کنترل می‌کند. بازیابی عملیاتی فایل باید مستقل و با احتیاط انجام شود، نه روی داده واقعی در آزمون.
- بکاپ سراسری SQLite سمت سرور شامل پیام‌ها/تاریخچه است، اما **Export معمولی JSON وب / Snapshot و Export ویندوز، بکاپ گفت‌وگو نیستند**. فایل‌های مالی، هویت کاربری خصوصی ویندوز، بکاپ پارسیان و مسیرهای محلی نباید به API وب ارسال شوند.
- Shell آفلاین PWA با Outbox پیام یکی نیست. **گفت‌وگو در وب بدون شبکه یا Session صف پایدار ندارد**؛ صف IndexedDB فعلی فقط برای Snapshot Sync است.

## تست‌های مربوطه

- `tests/web_gantt_chat_browser.test.cjs`: Chromium واقعی، Drag در RTL، ممانعت بازشدن کارت پس از Drag، تغییر مقیاس، Viewer، مجوزهای نمایش ویرایش/حذف پیام. این تست کامپوننت‌ها را در fixture ساختگی render می‌کند، نه جریان کامل حساب و API.
- `tests/web_server_api.test.cjs`: API واقعی، کاربر/ACL/CSRF، ارسال/Reply/Edit/Delete، تکرارناپذیری، حفظ نسخه قبل از ویرایش، انتقال کارت بین پروژه‌ها.
- `tests/web_conversation_migration.test.cjs`: DB ساختگی و دارای اطلاعات برای مهاجرت 1→3 و 2→3.
- `tests/web_server_cli.test.cjs`: Backup و Restore Verify و نگهداری رکورد گفت‌وگو.
- `npm run test:web`: Build، مجموعه تست‌های API/Sync/Browser با شواهد Exit Code.

## باقی‌مانده و خارج از این مرحله

- Outbox پایدارِ پیام‌ها و بازیابی پس از Crash / اتصال ضعیف، اعلان اشاره `@username` در وب، فایل پیوست، pagination بیش از ۳۰۰ پیام و بروزرسانی real-time.
- تست مرورگر یکپارچه ورود/ارسال/پاسخ/تغییر پروژه از داخل رابط کامل، تست چند دستگاه واقعی، تست EXE ویندوز و HTTPS عمومی.
- انتشار عمومی، نصب یا انتقال دیتای مالی جزو این تغییر نیست.
