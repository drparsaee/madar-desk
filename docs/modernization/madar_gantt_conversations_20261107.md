# مدار ویندوز: گانت و گفت‌وگوی پروژه/کارت

وضعیت: تغییرات در سورس `madar-desk` محلی؛ بدون ساخت Installer جدید یا به‌روزرسانی نسخه نصب‌شده کاربر.

## محدوده پیاده‌سازی

- `plannedStart` و `plannedEnd` مستقل از `dueDate`، `estimatedMinutes` و `actualMinutes`؛ اعتبارسنجی تاریخ معتبر و تقدم شروع بر پایان در Python Native Host.
- گانت با مقیاس روز/هفته/ماه، فیلتر، نمایش وابستگی، لینک کارت و جابه‌جایی دستی تاریخ؛ مشاهده برای Viewer و ویرایش برای نقش مجاز. زمان‌بندی خودکار وابستگی‌ها وجود ندارد.
- پنل زمان/گزارش قبلی همچنان مستقل است.
- گفت‌وگوی کارت و پروژه با Reply، Edit نویسنده، Delete نویسنده/مدیر، Tombstone، کنترل ACL و Idempotency در `collab.py`؛ خواندن گفت‌وگوی پروژه از `native_app.py` و `lan.py`.
- هماهنگی UI مدیر: حذف پیام دیگران نمایش داده می‌شود اما ویرایش پیام دیگران خیر؛ تصمیم قطعی با مجوز Backend است.

## مرز داده

- این نسخه با React/Python Native/LAN و ذخیره‌سازی محلی اجرا می‌شود و به Node/SQLite وب وابسته نیست.
- Export قابل‌انتقال `src/migration_export.js` تاریخ برنامه و وابستگی معتبر را نگه می‌دارد، اما عمداً **بکاپ کامل** نیست: پیام‌ها، Activity، حسابداری، باینری پیوست‌ها و حساب کاربران منتقل نمی‌شوند.
- بکاپ‌های پارسیان و اطلاعات مالی نصب‌شده خارج از دامنه هستند و در آزمون‌ها/مهاجرت وب دخالت داده نشده‌اند.

## آزمون و محدودیت

- Unit و Integration: `tests/gantt_model.test.cjs`، `tests/migration_export.test.cjs`، `tests/test_collab.py`، `tests/test_collab_bridge.py`، `tests/test_card_dependency_validation.py`.
- Build Vite اثبات اجرای قابل‌نصب EXE نیست. برای پذیرش نهایی، ساخت Installer، بررسی دستی رابط، ارتباط واقعی LAN چند کامپیوتر و بررسی Store قدیمی روی نسخه نصب‌شده لازم است.
